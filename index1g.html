Ejercicio 1g · Predecir el valor de expresiones

Antes de empezar

Los corchetes permiten leer un elemento de un array o un carácter de una cadena. length cuenta los caracteres de una cadena. Una comparación devuelve un booleano y ! lo invierte.

const datos = ["Sol", 7, false];
console.log(datos[0].length); // 3
console.log(datos[0][1]); // "o"
console.log(datos[1] > 3); // true
console.log(!datos[2]); // true

Tu turno

Abre la consola del navegador (F12 → Consola).

Predice el resultado de cada expresión y anótalo junto al console.log correspondiente. Después pulsa el botón para comparar tus respuestas con la consola.

Explicación

La cadena «Andres» tiene seis caracteres. El índice 1 de «Miguel» contiene la letra «i». La edad 61 es menor que 65 y !true da false.
