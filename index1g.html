Ejercicio 1g · Predecir el valor de expresiones

Antes de empezar

Los corchetes permiten leer un elemento de un array o un carácter de una cadena. length cuenta los caracteres de una cadena. Una comparación devuelve un booleano y el operador ! lo invierte.

const datos = ["Sol", 7, false];
console.log(datos[0].length); // 3
console.log(datos[0][1]); // "o"
console.log(datos[1] > 3); // true
console.log(!datos[2]); // true

Tu turno

Abre la consola del navegador (F12 → Consola).

Escribe en el comentario de la derecha de cada línea el resultado que esperas ver en la consola. Fíjate en el primer ejemplo: elementos[0] vale 0, y al compararlo con 0 mediante ==, el resultado es true. Después pulsa el botón para comparar tus respuestas con la consola.
