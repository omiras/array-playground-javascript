Ejercicio 1c · Modificar elementos por su índice

Antes de empezar

Asigna un valor a una posición concreta para sustituir el elemento de ese índice.

const palabras = ["hola", "dia"];
palabras[1] = "noche";
console.log(palabras); // ["hola", "noche"]

Tu turno

Abre la consola del navegador (F12 → Consola).

Cambia los elementos de las posiciones correspondientes para que los Reyes Magos queden en el orden Melchor, Gaspar y Baltasar.

Edita el último <script>, guarda el archivo y recarga la página.

Resultado esperado 
["Melchor", "Gaspar", "Baltasar"]
