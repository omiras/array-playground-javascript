Antes de empezar

Para contar cuántos elementos cumplen una condición, recorre el array y aumenta un contador cada vez que se cumpla.

const temperaturas = [18, 26, 22];
let diasCalurosos = 0;

for (let i = 0; i < temperaturas.length; i++) {
  if (temperaturas[i] > 25) {
    diasCalurosos++;
  }
}

console.log(diasCalurosos); // 1
