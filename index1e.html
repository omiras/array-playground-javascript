Ejercicio 1e · Concatenar tres arrays

Antes de empezar

concat crea un array nuevo. Coloca primero los elementos del array que llama al método y después los de los arrays que recibe como argumentos.

const mañana = [8, 9];
const tarde = [15, 16];
const noche = [20, 21];
console.log(mañana.concat(tarde, noche)); // [8, 9, 15, 16, 20, 21]

Tu turno

Abre la consola del navegador (F12 → Consola).

Usa concat para combinar primerosNumeros, numerosIntermedios y ultimosNumeros en secuencia. El resultado final debe ser [4, 8, 15, 16, 23, 42].
