Ejercicio 1e · Concatenar dos arrays

Antes de empezar

concat crea un array nuevo. Coloca primero los elementos del array que llama al método y después los del array que recibe como argumento.

const mañana = [8, 9];
const tarde = [15, 16];
console.log(mañana.concat(tarde)); // [8, 9, 15, 16]

Tu turno

Abre la consola del navegador (F12 → Consola).

Usa concat para combinar ambos arrays. El resultado debe quedar en orden numérico ascendente y conservar los valores repetidos.

Edita el último <script>, guarda el archivo y recarga la página.
