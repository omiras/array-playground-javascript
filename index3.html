Ejercicio 3 · Detectar un índice fuera del array

Antes de empezar

Los índices empiezan en 0. Para tres elementos, los índices que existen son 0, 1 y 2.

const frutas = ["pera", "uva", "kiwi"];
console.log(frutas.length); // 3
console.log(frutas[2]); // "kiwi"

Tu turno

Abre la consola del navegador (F12 → Consola).

Ejecuta el código y explica por qué el último mensaje dice «Pez siguiente: undefined». Como reto adicional, corrige el límite del bucle.

Edita el último <script>, guarda el archivo y recarga la página.

Resultado esperado

Antes de corregir el límite, la consola muestra:

Pez siguiente: Dory
Pez siguiente: Nemo
Pez siguiente: Shipho
Pez siguiente: Estrella
Pez siguiente: undefined

Después de corregirlo, la última línea desaparece.
