Ejercicio 1b · Obtener el último elemento con at

Antes de empezar

El método at acepta índices negativos. Un índice negativo cuenta desde el final del array.

const meses = ["enero", "febrero", "marzo"];
console.log(meses.at(-1)); // "marzo"

Tu turno

Abre la consola del navegador (F12 → Consola).

Asigna a ultimoPez el último elemento de peces usando at.
