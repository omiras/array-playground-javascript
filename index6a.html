Ejercicio 6a · Convertir nombres a mayúsculas

Antes de empezar

toUpperCase devuelve una cadena en mayúsculas. Puedes usar push para guardar cada resultado en un array nuevo.

const ciudades = ["Madrid", "Bilbao"];
const enMayusculas = [];

for (const ciudad of ciudades) {
  enMayusculas.push(ciudad.toUpperCase());
}

console.log(enMayusculas); // ["MADRID", "BILBAO"]
