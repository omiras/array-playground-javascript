Ejercicio 6a · Convertir nombres a mayúsculas

Antes de empezar

toUpperCase devuelve una cadena en mayúsculas. Puedes usar push para guardar cada resultado en un array nuevo.

const nombre = "Mario";
const nombresEnMayusculas = [];

const nombreConvertido = nombre.toUpperCase(); // "MARIO"
nombresEnMayusculas.push(nombreConvertido);

console.log(nombresEnMayusculas); // ["MARIO"]
