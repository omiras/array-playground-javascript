Ejercicio 6 · Depurar la búsqueda con while

Antes de empezar

Un while vuelve a comprobar su condición antes de cada vuelta. Muestra el índice dentro del bucle para averiguar qué posiciones llega a visitar.

const precios = [4, 8, 12];
let indice = 0;

while (indice < 2) {
  console.log(indice, precios[indice]);
  indice++;
}
// Aparecen los índices 0 y 1.
