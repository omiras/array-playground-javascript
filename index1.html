Ejercicio 1 · Acceder a elementos por su índice

Antes de empezar

Cada elemento ocupa una posición. El primer índice es 0 y el segundo es 1.

const colores = ["rojo", "verde", "azul"];
console.log(colores[2]); // "azul"

Tu turno

Abre la consola del navegador (F12 → Consola).

Cambia únicamente los dos console.log para mostrar Dory y Boby, en ese orden. Accede a cada nombre mediante su índice.
