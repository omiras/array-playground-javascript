Ejercicio 2 · Buscar a Nemo al recorrer un array

Antes de empezar

Dentro de un bucle, un if…else permite elegir qué hacer con cada elemento según cumpla una condición.

const tareas = ["leer", "descansar"];

for (let i = 0; i < tareas.length; i++) {
  if (tareas[i] === "leer") {
    console.log("Abre el libro");
  } else {
    console.log("Tómate un descanso");
  }
}
