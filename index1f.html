Ejercicio 1f · Calcular el total de reservas

Antes de empezar

La propiedad length indica cuántos elementos tiene un array. Puedes sumar la longitud de dos listas para obtener su total.

const lunes = ["Ana", "Luis"];
const martes = ["Eva"];
console.log(lunes.length + martes.length); // 3
