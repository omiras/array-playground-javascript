Ejercicio 5b · Devolver el resultado de una búsqueda

Antes de empezar

Una función puede devolver el resultado de includes directamente mediante return.

function hayTalla(tallas, tallaBuscada) {
  return tallas.includes(tallaBuscada);
}

console.log(hayTalla(["S", "M"], "M")); // true
