Ejercicio 6b (difícil) · Contar cuántas veces salió un seis

Antes de empezar

Usa un contador para registrar cada coincidencia. Inícialo antes del bucle y devuelve su valor después de recorrer el array.

function contarLluvia(dias) {
  let total = 0;

  for (let i = 0; i < dias.length; i++) {
    if (dias[i] == "lluvia") {
      total++;
    }
  }

  return total;
}

console.log(contarLluvia(["sol", "lluvia"])); // 1
