Ejercicio 8 · Aplicar un estilo a partir de un array

Antes de empezar

Puedes leer el nombre de una clase CSS mediante su índice y pasarlo a classList.add.

const tamaños = ["mediano", "grande"];
const titulo = document.querySelector("h1");
titulo.classList.add(tamaños[1]);

Tu turno

Actualiza seleccion para obtener fancy de estilosDisponibles mediante su índice. Comprueba que el párrafo cambia de estilo al recargar.

Este párrafo muestra el estilo aplicado.

Resultado esperado 
El párrafo de vista previa aparece con el estilo fancy.
