Ejercicio 8 · Aplicar un estilo a partir de un array

Antes de empezar

Puedes leer el nombre de una clase CSS mediante su índice y pasarlo a classList.add.

const tamaños = ["mediano", "grande"];
const titulo = document.querySelector("h1");
titulo.classList.add(tamaños[1]);

Tu turno

Asigna a seleccion el valor de estilosDisponibles[0], estilosDisponibles[1] o estilosDisponibles[2] que corresponda al estilo fancy.

Cuando resuelvas correctamente el ejercicio, este párrafo va a cambiar radicalmente de estilo.
