Ejercicio 1a · Crear un array con distintos tipos

Antes de empezar

Un array puede contener valores de distintos tipos. Separa los elementos con comas dentro de los corchetes.

const producto = ["Cuaderno", 4, true];
console.log(producto);

Tu turno

Abre la consola del navegador (F12 → Consola).

Crea un array con tu nombre, tu edad y un booleano que indique si estás trabajando actualmente. Muestra el array en la consola.

Edita el último <script>, guarda el archivo y recarga la página.
